# Contributing to Synth

Open an issue or pull request in AlexHHPS/synth. Keep acoustic inference local,
preserve folder authorization and transcript/document version boundaries, and
never add credentials, real recordings, profiles or organization infrastructure
to source or fixtures. Use synthetic data for public tests. Maintain the MIT
license and third-party notices. Follow docs/synth/installation.md for build
checks and scripts/audit-public.py for publication checks. Installer releases,
new model integrations and supported-platform claims need their own evidence.
